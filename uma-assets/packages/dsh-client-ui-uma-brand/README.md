# @deepseek-ai/dsh-client-ui-uma-brand

English | [中文](README.zh.md)

## Summary

The Web application uses the UMA Studio wordmark in the expanded sidebar and its cloud mark in the rail and conversation hero. The wordmark uses transparent SVG paths with their intrinsic aspect ratio in a 156 × 26 px sidebar allocation; light and dark palettes select primary and reverse artwork. Deployments can retain the parent Umayun lockup or a custom visible product name.

## Use this package

The Web bundle mounts this plugin with the product name:

```yaml
- id: ui-uma-brand
  name: '@deepseek-ai/dsh-client-ui-uma-brand'
  config:
    name: UMA Studio
```

| Field | Default | Meaning |
|---|---|---|
| `name` | `UMA Studio` | `UMA Studio` selects the product SVG; `优码云` retains the parent lockup, and other names render beside the cloud mark |

The package publishes referenced SVG and PNG files through `./assets/*`. The client build emits them under `lib/assets`; keep that directory in packaged distributions. The Studio SVG contains vector paths without an embedded bitmap or a font dependency. The conversation hero renders the mark at 1.4 times the requested square edge (48px for the standard 34px seat), with its original aspect ratio and a 12px total gap to the headline.

<a id="understand-the-implementation"></a>
## Understand the implementation

<details>
<summary>Implementation internals — click to expand</summary>

The plugin registers the complete expanded identity at `sidebar.brand.identity`, separate fallback mark/name occupants, and the hero mark. Priority `-1` selects this deployment identity alongside an official default occupant. Slot injection and registration teardown follow the declaring shell’s lifecycle.

The private `src/client/uma-brand.css` owns the neutral black-and-gray palette, primary/reverse artwork aliases and translucent satin-composer material, including both palettes and reduced-transparency selectors. The plugin injects `theme` and registers the complete sheet through `ctx.theme.overrideStylesheet` inside `ctx.effect`; the theme presenter places it after `design-platform.css` and before `focus.css`. Unload and HMR remove the override and restore the underlying palette. The focus-ring colors are `#505257` in light mode and `#C3CBD7` in dark mode. Components preserve the original artwork with `object-fit: contain`; no label, tool, or Session record is generated by the images.

</details>

<a id="model-experience"></a>
## Model Experience

### Presentation only

#### What the model sees

Nothing. Browser branding uses `sidebar.brand.identity`, `sidebar.brand.mark`, `sidebar.brand.name`, and `conversation.hero.brand.mark` without tools, prompt sections, or Session events.

#### Token effect

None; the artwork and product name remain browser presentation.

#### KV Cache effect

None; the package neither assembles nor sends model requests.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- Desktop installer icons and native welcome-window branding have separate owners.
- Names other than `UMA Studio` and `优码云` use text beside the cloud mark.
