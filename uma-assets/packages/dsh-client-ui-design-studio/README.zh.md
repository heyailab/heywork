# @deepseek-ai/dsh-client-ui-design-studio

[English](README.md) | 中文

## 概述

设计工作台浏览内置设计参考、令牌和组件预览。会话“更多操作 → 任务详情”在现有右侧面板中查看当前项目的检查、验收、问题、修复、任务和资料；准备验证或修复只追加当前会话草稿，不自动发送。目录与证据展示不请求模型。

固定的 UMA Design 入口打开完整图库和已保存的设计项目。UMA 发布版展示配色、字体、设计契约和组件预览；完整参考文档保留在本地 Agent 资源库中。维护者可在源码构建的 profile 中设置 `showInternalLibrary: true` 查看原文。

## 使用

在 **UMA 运维** 中保存服务器的主机、端口、用户名和认证方式，支持密码、私钥和本机 ssh-agent。连接前可与管理员核对 SSH 主机指纹。已连接的服务器各有终端，切换服务器时仍保持连接。桌面版将服务器资料和凭据保存在[本地加密文件](../../../apps/desktop/README.zh.md#local-desktop-settings)。浏览器会话可建立临时连接。

**概况** 显示 Linux 的 CPU、内存、交换空间、磁盘及网络指标。操作页可查看磁盘、进程、服务、日志和容器，并在远端用户具备权限时启动、停止或重启服务和容器。**文件** 支持通过 SFTP 浏览、传输、新建目录、重命名和删除文件或空目录。**Agent 访问** 将所选服务器授权给指定会话。每条命令需审批，断开服务器连接会撤销该服务器的授权。

连接 SSH 后打开 **远程桌面**，填写服务器回环地址上的 VNC 服务端口。SSH 服务需要允许转发到该端口。按 VNC 服务要求填写连接凭据。选中 **仅查看** 可禁用远程输入，也可在画面内点击并使用键盘和鼠标。网络断开后可手动重连。桌面查看器使用 [noVNC 1.5.0](https://github.com/novnc/noVNC/tree/v1.5.0)，许可为 [MPL 2.0](https://www.mozilla.org/MPL/2.0/)。 使用 **全屏** 扩大远程桌面。退出全屏后，远程桌面和 SSH 终端保持连接。

目录区分品牌参考与通用视觉风格，支持行业分类筛选，并检索名称、规范 id 和别名（含整理的中文品牌名）。每个已安装系统都有生成的卡片和按需加载的详情模块。复制提示词或启动设计会话时会携带规范的系统 id。卡片显示默认根级配色，不混入条件式深色主题覆盖。配色值会展开颜色函数中的别名，并排除阴影或未解析的自定义属性。

这些页面共用 PageLayout、PageHeader、NativeSelect、Input、Button 和卡片组件；功能样式负责业务布局，不重复维护字段或卡片材质。图库每页展示 36 项，分页控件位于卡片下方。搜索和分类筛选覆盖完整目录，并重置分页；翻页后从页面顶部开始。参考详情的「返回」固定在滚动区上方的左侧，返回图库时恢复页码和滚动位置。品牌卡片共用配色与操作布局，不为每张卡片单独计算背景模糊。

交付工作台区分文档结构就绪与关联当前源码的工程验收；文档元数据中的批准状态只是声明，不代表有人员身份记录的审批。任务目录支持搜索、分页、重新打开会话和明确确认后的轮次中断，不把空闲状态视为完成。验收编辑器将标准关联到发现的检查命令，按读取到的版本保存；冲突和保存结果不明时保留输入。项目检查在确认前展示 argv，Host 接收执行时拒绝已变更的命令；启动检查不等于通过检查。再次执行前应刷新读取保留结果。

工程验证区通过共享资源提供者读取原生 Coding Workbench，独立展示当前源码扫描完整性、可执行验收项、有效通过记录与未解决问题。刷新会重新读取工程证据和文档；验证入口准备使用内置验收与检查工具的标准开发会话草稿，不会自动发送。文档范围与检查阶段选择器和 Host 门禁工具复用同一套纯函数规则。

在 Web 组合中挂载：

```yaml
- id: ui-design-studio
  name: '@deepseek-ai/dsh-client-ui-design-studio'
```

插件保留 `main` keyed 页面 `design` 与兼容路由 `delivery`，为设计和 UMA 运维注册 `sidebar.panellist`。任务详情通过会话菜单打开，并复用右侧面板。设计工作台读取所选会话的 `.design/` 项目，显示契约完整性、预览 DESIGN.md，并可打开所属会话；图库中的每套设计系统都可在沙箱 iframe 中预览组件。选择设计系统后可 **定制设计简报**：引导表单收集产品、界面类型、受众、语气、密度、必需页面与约束，再以结构化提示词启动 UI Design Agent；提示词先读取 `design_context`，保留已确认品牌与现有实现，仅在缺少设计基础时使用 `design_project_create`。正式 UI 使用当前技术栈，单文件 HTML 只用于明确的原型请求。选择交付阶段可打开其 Markdown；缺失或未就绪的工件提供 **让 Agent 补齐**，以必需章节与占位符规则为提示词启动 UMA 交付团队。门禁面板会列出当前阻塞交付的工件，并可复制结构化门禁报告。

任务详情始终核对所属会话与项目关联，不跟随其他项目的全局选择；关联移除后隐藏旧证据。项目资料按需读取，缺少资料不强制用户补写整套文档。设计入口与兼容路由仍可准备普通 Agent 草稿。

交付工作台列出已注册工作区，包括尚无会话的目录。选择空工作区会初始化或复用真实空会话，不导航也不请求模型；目录校验与工件读取沿用现有会话范围的文件权限。缺失文件显示空状态，无法读取或被截断的文件显示可重试错误。启动任务会在所选工作区准备草稿并保留原有草稿内容；所选工作区被移除后需重新选择，切换后完成的旧请求不会导航。Coding 分类通过标准开发预设提供影响分析、代码审查和报错诊断。文档检查只判断章节与占位符完整性，不代表测试已运行或人工已批准。

目录卡片与详情标题使用本地化的参考摘要，搜索也匹配这些可见文案。完整设计契约、原始作者归属与许可证声明保留在内置参考资产中。

设计工作台使用完整安装目录，按需加载选中系统的预览。目标选择器直接指定本地导入工作区，包括尚无会话的工作区；已选工作区消失时，不悄悄换到其他项目。参考系统可在那里准备标准前端草稿；已有设计项目可读取实际保存的 HTML 版本，并继续所属会话，保留历史、工作目录与已有草稿。项目原型在禁用脚本的预览中提供适应面板以及 390、768 和 1280 px 固定宽度，用于检查 CSS 断点。面板窄于所选宽度时，预览区域可以横向滚动。交给会话开发前，必须成功加载所选文件，刷新后也需要重新加载成功。交互应在运行中的前端检查。 工程验证列出未满足的验收条目和每个条目仍缺少有效结果的检查名称。

页面标题与操作栏使用公共 `PageHeader` 和 `Button` 组件，工作区选择器采用统一控件尺寸。分类标签与分类搜索均本地化，等价的导入分类共用一个筛选项。参考表单的焦点只绘制在同一条内侧边缘。

已保存的设计项目每页显示十二个，完整目录列表中的每个项目均可访问。目录列表被截断时明确报错，不将不完整列表呈现为完整结果。项目元数据在请求期限内依次读取，限制并发文件请求。

<a id="model-experience"></a>
## 模型体验

### 仅展示

#### 模型看到什么

无。页面只注册 `main` 与 `sidebar.panellist` 界面、读取工作区文件用于展示，并预填会话提示词；不新增工具、提示词段落或 Session 事件。

#### Token 影响

无；页面不构造模型输入，也不改变请求 token。

#### KV Cache 影响

无；该包不组装或发送模型请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 目录由内置设计系统生成；新增系统需要重新生成 `src/client/catalog.ts`。
- 章节检查与占位符规则来自 `uma_gate_status` 共用的 `dsh-util-uma-delivery` 契约；工件状态与检查结果通过初始化后的会话从所选工作区实时读取。
- 页面只预填提示词并打开会话，不会代替用户提交。
- 显示默认根级令牌值；同一份样式表中的简单 `var()` 别名会被解析，`color-mix()` 保留为 CSS 表达式。
