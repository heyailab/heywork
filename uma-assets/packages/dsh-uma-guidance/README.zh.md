# @deepseek-ai/dsh-uma-guidance

[English](README.md) | 中文

## 概述

通过已登录的 HEY 账号请求针对当前任务的工程、设计或评审指导。已选托管模型和会话任务预算承担一次额外推理调用。只上传明确提供的任务文本，私有参考资料的名称、正文和使用详情留在服务端。结果只是工作建议，不会执行工作或授予文件系统权限。源码变化、账号变化和提交结果不确定时，不会自动交付结果或重新提交。

请求保留当前托管提供方的协议。不可变回执必须与该协议一致；协议不同或缺失时拒绝接收。同一操作 ID 更换协议会产生冲突。

<a id="use"></a>
## 使用本包

将 `@deepseek-ai/dsh-uma-guidance` 作为 Host 插件，与账号、预算、已导入工作区和编码服务一同挂载。配置规范化的 `origin`；必须使用 HTTPS，除非 `allowLoopbackHttp` 明确允许 `127.0.0.1`。`requestTimeoutMs` 限制提交时长，`recoveryTimeoutMs` 限制读取与取消时长，`maxResponseBytes` 限制完整 JSON 响应。私有资源和能力发布由服务端管理，见[平台 API](../../../apps/hey-platform-go/README.zh.md#private-guidance-api)。

`uma_guidance` 提供 `capabilities`、`request`、`status` 和 `cancel`。请求必须包含 `mode: managed`、已选 HEY 账号模型、能力、明确的任务文本，以及由 8–64 个 ASCII 字母、数字、下划线或连字符组成的 `operation_id`。每个新意图使用不同的操作名，并保留它用于恢复。自定义提供方请求会在本地失败，不会重定向其流量或读取其 API 密钥。能力发现和恢复不创建推理请求。

提交前，工具对已导入工作区 ID 和编码工作台的完整源码指纹计算摘要；完成时若观察值改变，结果会被保留而不交付，只返回公开的账务引用。指纹覆盖范围遵循工作台的源码排除规则。调用方仍须评审建议文件并使用普通写入权限。不会自动上传文件或整个仓库快照。

<a id="transport"></a>
## 传输与生命周期

操作键由实际调用会话和提供的操作名派生。网络故障只触发一次只读查询，不会再次提交。取消会进行有时限的本人运行查询和取消请求；结果未确认时，仍可通过会话已记录的工具参数恢复。插件卸载会中止并等待活动工作结束，然后才能释放依赖。

请求前和响应后都会核对捕获的账号凭据。拒绝重定向，凭据只发送到配置的签发方。响应在交付给模型前会拒绝未知字段、非法相对工件路径和超限内容。账号变化或凭据刷新时不会交付旧响应；使用当前账号恢复仍受服务端所有权检查。鉴权错误、提供方错误和畸形 JSON 不会暴露原始响应体。

<a id="model-experience"></a>
## 模型体验

### 当前任务指导

#### 模型看到什么

模型看到 `uma_guidance`、公开工具描述、`operation_id`、操作状态和针对当前任务的结果，不会收到私有资源目录或参考正文。失败时不会声称使用了不可用的参考资料。

#### Token 影响

一次额外托管模型请求消耗当前任务预算。公开结果文本进入普通会话历史，私有模型输入留在服务端。

#### KV Cache 影响

本地工具 schema 保持前缀稳定。返回的指导追加到普通工具历史，不会用私有资源替换本地系统提示词。

## 已知限制与后续工作

<a id="limitations"></a>

- 工具要求使用设备凭据的 HEY 账号，以及具有完整源码指纹的已导入工作区，不支持通过独立 SDK 密钥使用私有指导。运行时的源码排除项也不参与新鲜度检测。当前服务端采用已发布模型的主协议和默认思考配置；保留用户明确选择的其他协议及思考等级仍属于必须完成的适配工作。完整资料导入、更广泛检索、移除本地私有资产及私有模式质量对比仍属于迁移工作；仅有此工具并不能证明保密或任务质量不变。
