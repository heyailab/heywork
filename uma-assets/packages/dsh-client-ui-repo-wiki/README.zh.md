# @deepseek-ai/dsh-client-ui-repo-wiki

[English](README.md) | 中文

新建 Wiki 生成任务前必须已选择可用的默认模型。未选择时，页面会提示用户登录，或配置并选择个人模型。

## 概述

打开**UMA 知识库 → 项目 Wiki**，选择已注册工作区，生成中文或英文知识，并对照源码行范围阅读文档。生成由真实 Agent 任务执行，按文档持久化进度；暂停、继续、增量更新和重新生成会保留旧版本。可导出可移植知识，也可导入已放入项目的知识包。页面自动列出已导入的本地工作区，首次生成须主动发起。

## 使用本包

Web 组合包默认挂载此页面。同一工作区、分支和语言的增量更新复用首次生成的本机 Wiki 会话。**生成 Wiki** 会提交已配置的任务，不替换现有对话草稿。**查看生成任务** 可查看完整模型与工具执行记录。选择源码引用可查看有界且经过版本校验的片段。

工作区列表直接复用左侧导入的本地文件夹，无需另建项目或连接 Git。总览提供生成状态筛选与真实版本数量，进入项目后可折叠的文档树会保留在概览和正文旁。

```yaml
- id: ui-repo-wiki
  name: '@deepseek-ai/dsh-client-ui-repo-wiki'
```

| 字段 | 默认值 | 含义 |
|---|---|---|
| `generationRefreshMs` | `3000` | 活跃任务的进度刷新间隔 |
| `autoUpdateIntervalMs` | `30000` | 已启用版本的源码指纹检查间隔 |
| `autoUpdateDebounceMs` | `1500` | 开发任务完成后的检查延迟 |
| `autoGenerateOnOpen` | `false` | 无需手动请求就生成缺失版本 |
| `autoUpdateDefault` | `true` | 初始自动更新选项 |

生成设置应用于下一次提交的生成或更新。默认须主动发起首次生成，自动更新默认勾选，在应用打开期间运行。源码指纹能识别 Git 未提交修改和普通文件夹的变化。提交失败后，等待源码指纹变化或手动重试。如果源码检查失败，可点击「重试」恢复检查。已暂停的写入检查点可手动继续。

应用按工作区与语言在本机保存自动更新选项。取消勾选立即撤销后续调度；已经运行的任务需单独暂停。已停止的写入检查点需要手动继续。当前应用实例中的并发检查会共用一次请求。

<a id="understand-the-implementation"></a>
## 实现说明

<details>
<summary>实现细节 — 点击展开</summary>

知识库页面声明 `main.knowledge.wiki`，本插件将阅读器注册到该位置，不再提供单独的侧栏入口。工作区与会话身份均显式传入，阅读器不借用无关的当前对话。只读目录、源码观测和文件读取使用以工作区身份调用的 `projectWiki` 远程服务，无需关联会话；生成使用 Session Controller；UI 所有者离开时取消其请求。

仅在展开图示预览时加载 Mermaid。严格解析禁用交互和配置覆盖，生成的 SVG 作为不执行交互的图像显示。文档 Markdown 仍然保留，包括原始图示源码。读取失败会保留已有内容，并提供重试操作。

页面及其编辑器使用公共 [UI 基础组件](../ui-primitives/README.zh.md)统一页面布局、卡片和表单控件；包内样式只负责内容排列。

</details>

工作区卡片分别呈现名称、路径、状态和公共操作按钮。路径最多显示两行，悬停可查看完整值。工作区读取失败时显示不可用提示，不再显示加载状态。

<a id="model-experience"></a>
## 模型体验

### 明确提交的生成任务

#### 模型可见内容

生成、更新、导入和继续会向普通 `repo-wiki` 会话提交可见提示词。阅读和检索页面 UI 不发起模型请求。

#### Token 影响

仅已提交的 Agent 任务和明确启用的自动更新消耗模型 token。

#### KV Cache 影响

提示词使用正常 Session 流程，本页面不组装供应商请求。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 界面文案提供中文与英文，其他应用语言使用英文回退。
- 自动调度由运行中的客户端负责，不是持久化 Host 队列，也不提供多个应用窗口共享的任务预留。
- 导入接受已放入 `.uma/wiki/` 下的可移植 JSON 知识包；云端团队账号同步属于独立能力。
- 源码预览最多显示所引用版本的 500 行。该版本不可用时，更新 Wiki 后可查看新的引用。
