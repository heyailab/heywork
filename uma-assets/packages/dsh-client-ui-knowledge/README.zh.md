[English](README.md) | 中文

## 概述

从桌面侧栏管理团队规范和项目资料。导入文件/文件夹或编写 Markdown 笔记，查看真实解析进度、阅读来源片段、测试检索，并关联已导入的工作区。编码任务随后会自动使用相关依据。从本页提问会进入已有会话流程并保留草稿。

## 使用本包

“开发经验”提供集合选择、搜索、状态筛选、分页、详情、编辑、审阅、撤回、导出、版本记录、恢复为新候选及逐项反馈的批量撤回/删除。表单失败保留输入，版本冲突不覆盖其他修改。页面默认打开本机全局经验库。项目集合可选择额外记录从失败到通过的检查。经验经人工审阅后可供检索，仍需按当前项目重新验证。

侧栏只提供一个 UMA 知识库入口，内含**资料库**与**项目 Wiki**。资料库管理团队和项目集合，Wiki 阅读器通过 `main.knowledge.wiki` 注册。切换时保留资料库导航来源；Wiki 提供方停用时返回资料库，不显示空白面板。 在 macOS 上，可以拖动顶部导航行的空白区域移动窗口。资料库和项目 Wiki 按钮仍可点击。标签悬停强调只用于支持悬停的指针；触屏设备仍保留当前分区的选中强调。

在桌面侧栏打开**知识库**。为一个已有工作区创建项目知识库，或为显式选定的工作区创建团队知识库。导入本地来源并等待实际就绪，再通过**检索测试**检查依据。文档可以停用、归档与恢复，历史快照仍可阅读。 窗口较矮时，知识库表单在固定标题和底部操作之间滚动，文档预览和笔记表单在固定标题下滚动。

UMA 资料库顶部的 **内置技术规范** 打开指南浏览器，知识库详情页也可使用。可按主题、技术语言及内容语言筛选，预览原创摘要与来源/许可链接，选择指南并明确指定已有目标知识库。带版本和语言的文档名称便于追溯，每篇指南使用 `createNoteIfAbsent` 导入；即使同名文档已被编辑、停用、归档或跟踪本地文件，也会保留原内容。普通笔记的编辑方式不变。

结果逐项报告入队、未变化/跳过及失败。取消操作停止剩余提交，已接收任务仍可查看并按正常流程解析；入队不代表就绪。导入不会修改知识库启用状态或工作区关联。用户启用并关联已有就绪知识库后，开发上下文会通过现有检索为团队提供相关依据；仅打开此对话框不发起模型请求。

桌面选择复用现有原生文件/目录桥接。本地来源可在应用打开时跟踪变化，浏览器兼容上传会创建快照。知识只保存在当前安装环境；界面会区分团队分组、员工账号和跨机器共享。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `showBuiltinStandards` | 由 UMA 发行配置启用 | 在资料库顶部提供内置技术规范入口 |
| `refreshMs` | 2000 | 页面打开期间的元数据与进度刷新间隔 |

## 实现说明

<details>
<summary>实现细节 — 点击展开</summary>

页面使用根 slot、类型化语言字典、工作区 store、生成的 `remote.knowledge` 方法和现有会话所有者。组件接收领域操作，不接收 Cordis Context。卸载会取消所属请求，延迟响应不能覆盖其他知识库，短暂读取失败会保留现有内容。重新打开页面可保留导航状态。

[Host 包](../../knowledge/knowledge/README.zh.md) 负责解析、持久化、来源有效性与检索范围。页面区分队列接收与完成状态，并展示逐文件导入失败。引用通过已有文件预览打开不可变解析 Markdown。

页面及其编辑器使用公共 [UI 基础组件](../ui-primitives/README.zh.md)统一页面布局、卡片和表单控件；包内样式只负责内容排列。

</details>

<a id="model-experience"></a>
## 模型体验

### 关联开发知识

#### 模型可见内容

阅读目录、导入普通文档和全文检索测试不会提交对话提示词。**在会话中提问**会在标准开发 Session 中准备明确问题；`UMA_KNOWLEDGE_BASE` 标记将检索收窄到选定且已关联的知识库。

#### Token 影响

只有明确发起的对话任务和已配置向量操作消耗模型 Token，本地全文管理不消耗对话模型额度。

#### KV Cache 影响

本页不组装提供方请求，模型依据与持久化快照由 Host 上下文插件负责。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 提供中英文文案，其他语言回退到英文。
- 团队分组是本机组织方式，不提供邀请用户或 SSO 界面。
- 扫描 PDF 需要文字/OCR 来源；配置向量提供方前，混合检索不可用。
